## Design Context

### Users

Recruiters, builders, and potential collaborators scanning the GitHub profile to understand Kita's work, interests, and activity quickly.

### Brand Personality

Playful, curious, and hacker-minded. Technical credibility with anime energy, controlled chaos, and late-night-builder personality.

### Aesthetic Direction

Dark, expressive GitHub profile with warm accents, monospace character, and an asymmetric desktop composition. Keep the existing animated introduction and One Dark stats card as recognizable anchors.

### Design Principles

- Lead with personality, then support it with credible activity data.
- Prefer playful technical details over generic corporate polish.
- Keep information scannable despite the expressive tone.
- Use asymmetry intentionally: identity on the left, proof on the right.
- Preserve readable fallbacks within GitHub README rendering constraints.
